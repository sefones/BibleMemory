# Bible Memory Skills (Verse Card) — v2.6

## What's new in v2.6: verse text fills in automatically

- **From Find a verse:** tapping a search result (or a topic verse) now opens the Add screen with the reference filled in *and* the verse text fetched for you. Check it, then tap Save.
- **On the Add screen:** a new **Fill in verse text** button fetches the text for whatever Book / Chapter / Verse / Version is selected, so it works when you add a verse manually too.
- **Which versions work:** KJV, WEB, ASV and YLT (YLT is New Testament only). These are public domain and come from bible-api.com.
- **Copyrighted versions (NIV, ESV, NLT, and others):** the text can't be filled in automatically. The app tells you so, and you paste the text as before (Bible.com paste still works). Tip: switch Version to KJV, WEB or ASV to auto-fill.
- **Needs internet.** If you're offline, or the free service is busy, the app says so and you can paste the text instead. The service allows about 15 lookups per 30 seconds, which is plenty for normal use.
