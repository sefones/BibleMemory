# Bible Memory Skills — Release Notes v2.4

## Changelog

### v2.4
- Added a **📤 Share** button on the home screen (next to Export and Import) that sends all of your saved verses to someone.
- On phones it opens the normal share menu (Messages, WhatsApp, email, AirDrop, etc.) with the verses attached as a `.txt` file.
- If an app can't take a file, the verses are shared as plain text instead.
- On a computer, or anywhere the share menu isn't available, **Share** copies the verses so they can be pasted into a message or email.
- Anyone receiving the verses can tap **Import** and choose the file, or paste the shared text into the **Verse text** box on the Add Verse screen to add every verse at once. Verses they already have are skipped.
- Version number now shows **v2.4**.
